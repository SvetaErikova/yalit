- -theme-dark

3. Баннер
помимо стандартных баннеров есть баннер для главных страниц - block_banner-main
а так же доп класс - block_banner-fit_content - Высота не задана и складывается из контента
4. Контакты
у каждого отеля свои координаты для карты - подставляются в     <div id="map" data-coords="[55.811573, 49.132474]"></div>
5. Каскад: новые:
-callouts, info-card,list-table, advantages-cards

6. картинка текст
есть доп классы
- по соотношению картинки либо декор (все в одной выпадашке)
- по теме

7. Блок лист
- может иметь темы
8. Галерея
есть галерея блок листом (используем на страницах)
а есть детальная галерей(страница галерея), там разбивка по группам

в кастомном блоке на главной есть табы - они не должны попадать в обработчик с загрузкой контента
обязательно сохранить класс страницы для:
- специпредложений (page-special)
- главной (page-main)
- главной отеля (page-main-hotel)
- об отеле (page-about)

лого меняется в шапке и футере , награды зависят от отеля

в карточках афиши есть плашка с логотипом (подтягивается от отеля) - туда подтягивается лого с шапки (свг или img)
HOTEL_POINTS - массив для координат карты - на главной выводятся все, а на детльных отеля только нужный
