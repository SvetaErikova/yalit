3. Баннер
помимо стандартных баннеров есть баннер для главных страниц - block_banner-main (в зависимости класса страницы page-main или page-main-hotel они чуть отличаются)
а так же доп класс - block_banner-fit_content - Высота не задана и складывается из контента
4. Контакты
   HOTEL_POINTS - массив для координат карты - на главной выводятся все, а на детльных отеля только нужный
5. Каскад: новые:
-callouts, info-card,list-table, advantages-cards, image-link ,js-hidden-content(не уверена что шорт код)

6. картинка текст
есть доп классы
- по соотношению картинки либо декор (все в одной выпадашке)
- по теме

7. Блок лист
- может иметь темы
8. Галерея
есть галерея блок листом (используем на страницах)
а есть детальная галерей(страница галерея), там разбивка по группам

в кастомном блоке на главной есть табы - они не должны попадать в обработчик с загрузкой контента, и в целом на табах есть слушатели

обязательно сохранить класс страницы для:
- специпредложений (page-special)
- главной (page-main)
- главной отеля (page-main-hotel)
- об отеле (page-about)

лого меняется в шапке и футере , награды зависят от отеля

- в карточках афиши есть плашка с логотипом (подтягивается от отеля) - туда подтягивается лого с шапки (свг или img)
- отдельный блок фак с формой
- в попапе с отелями - один отель имеет две свг со звездами

имеют темы:
- блок лист
- картинка текст
- about-media


заготовки:
- hotel-group


- у какого то из отелей номера разбиты по корпусам - должна быть разводящая с корпусами и разводящая с номерами (карточки одинаковые)
